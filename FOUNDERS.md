# Batch 001

The first production run is finite. Everyone who pre-orders before the
co-packer order is placed is in Batch 001, and this file is the roster.

It is committed to the public repo before the first run ships. Once the batch
closes, the closing commit is tagged `batch-001` and no name is ever added
below that line. Later batches get their own sections. There is no way to buy
into this one afterwards, which is the entire point.

## The roster

Empty until the first pre-order. Names appear in the order the pre-orders land.

| # | Founder | Joined |
|---|---|---|

## How a name gets here

1. Pre-order any paid plan before the batch closes.
2. Tick the founders box at checkout and give us the handle you want shown.
3. The name lands here in the next commit, in order of pre-order.

**Opting in is required and it is a separate action from ordering.** If you do
not tick the box you are still in Batch 001, you still get everything the batch
carries, and your name simply is not printed. Buying something is not consent to
be listed in public, and we are not going to treat it as though it were.

## What is published, and what never is

Published: exactly the handle you typed. A GitHub username, a first name, a
company, a pseudonym, whatever you want to be called.

Never published: your email, your order contents, your address, your payment
details, or anything else you gave us to ship a drink. This file is generated
from an opt-in list, not from the orders table.

**To be removed:** email `support@zeroshothq.dev` and we take the line out in
the next commit, no questions and no reply required. Git history keeps the old
commit, so removal means the name stops appearing, not that it never existed.
If you want it gone from history too, say so and we will rewrite the file's
history and force-push it, which is a thing we will actually do rather than a
thing we say.

## Why this exists

Engineers have a status medium, and it is not a mug. It is a repo. Being in the
contributor list of a thing that shipped is permanent, public, and legible to
exactly the people whose opinion you care about.

Batch 001 is small because first production runs are small. That is not
scarcity marketing, it is a co-packer minimum. We are choosing to make the
constraint mean something instead of hiding it.
